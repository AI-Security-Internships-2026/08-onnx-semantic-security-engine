# CSE-CIC-IDS2018 Dataset

## Overview
- **Dataset Name:** CSE-CIC-IDS2018 (Communications Security Establishment & Canadian Institute for Cybersecurity)
- **Source URL:** https://www.unb.ca/cic/datasets/ids-2018.html
- **Format:** CSV / Parquet (CICFlowMeter flow features)
- **Extracted Flow Tool:** CICFlowMeter-V3
- **Role in Study:** In-Distribution (ID) Training, Validation, and Calibration Source

## Preprocessing & Alignment
- **Raw Features:** 76-80 features generated by CICFlowMeter.
- **NF-Standardized Subset (13 Features):**
  1. `Flow Duration`
  2. `Total Fwd Packets`
  3. `Total Backward Packets`
  4. `Fwd Packets Length Total`
  5. `Bwd Packets Length Total`
  6. `Packet Length Max`
  7. `Packet Length Min`
  8. `Protocol`
  9. `Fwd Packet Length Max` (approximate to NetFlow `MAX_IP_PKT_LEN`)
  10. `Fwd Packet Length Min` (approximate to NetFlow `MIN_IP_PKT_LEN`)
  11. `Flow Bytes/s` (approximate to NetFlow `SRC_TO_DST_SECOND_BYTES`)
  12. `Init Fwd Win Bytes` (approximate to NetFlow `TCP_WIN_MAX_IN`)
  13. `Init Bwd Win Bytes` (approximate to NetFlow `TCP_WIN_MAX_OUT`)
- **Cleaning:** Dropped `Timestamp`, removed `inf`/`-inf`, dropped `NaN`, deduplicated rows.
- **Split:** 80% Stratified Training, 20% Held-Out Testing (stratified random seed 42).
- **StandardScaler:** Fitted solely on training partition (`experiments/standard_scaler_nf.joblib`).
